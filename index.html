Step-by-step installation

Step 1 — Clone the repository

Get the code

Clone the repo and enter the project directory. Replace your-username with your GitHub handle.

terminal
# Clone via HTTPS
git clone https://github.com/your-username/bitcoin-ds-platform.git
cd bitcoin-ds-platform

# Or clone via SSH (recommended)
git clone git@github.com:your-username/bitcoin-ds-platform.git
Step 2 — Python virtual environment

Isolate dependencies

Always use a virtual environment. This keeps your system Python clean and makes the project reproducible.

terminal — macOS / Linux
python3.12 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
terminal — windows
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

Step 4 — Environment variables

API keys and secrets

Create a .env file in the project root. Never commit this file. It is already in .gitignore.

.env — template
# Free APIs — no key needed for Modules 0–4
# COINGECKO_API_KEY=optional_for_higher_rate_limits

# Supabase (Module 5) — get from supabase.com
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your-anon-key

# MongoDB Atlas (Module 5)
MONGODB_URI=mongodb+srv://user:pass@cluster.mongodb.net/bitcoinds

# Anthropic (Module 16+)
ANTHROPIC_API_KEY=sk-ant-your-key

# Glassnode (Module 9+ on-chain features, free tier)
GLASSNODE_API_KEY=your-key
Step 5 — Run the website locally

Open the platform

This website is a single HTML file with zero build step. Open it directly — or serve with Python's built-in server for proper asset loading.

option A — direct open (simplest)
open index.html # macOS
start index.html # Windows
xdg-open index.html # Linux
option B — local server (recommended)
# Python built-in (no install needed)
python -m http.server 8080
# then open http://localhost:8080

# Or with Node.js
npx serve . -p 8080
Step 6 — Launch Jupyter notebooks

Open the notebook environment

terminal
# Classic notebook interface
jupyter notebook

# JupyterLab (recommended — more features)
jupyter lab

# Specific notebook
jupyter lab notebooks/module0_bitcoin_foundations.ipynb
Step 7 — Git & GitHub workflow

Version control every notebook

initial setup
git init
git remote add origin git@github.com:your-username/bitcoin-ds-platform.git
git add .
git commit -m "feat: initialise Bitcoin DS platform"
git push -u origin main
recommended .gitignore
.env
.venv/
__pycache__/
*.pyc
.ipynb_checkpoints/
.DS_Store
*.egg-info/
dist/
data/raw/ # large data files — use DVC or Git LFS
module-by-module workflow
# Feature branch per module
git checkout -b module/01-oop-bitcoin
# ... do work ...
git add notebooks/module1_oop_bitcoin.ipynb
git commit -m "feat(m1): add BitcoinWallet and Transaction classes"
git push origin module/01-oop-bitcoin
# Open PR on GitHub → merge to main
Step 8 — Deploy Streamlit dashboard (Module 6)

Ship the live dashboard

local run
streamlit run streamlit_app/bitcoin_dashboard.py
deploy to Streamlit Cloud (free)
# 1. Push streamlit_app/ to GitHub
# 2. Go to share.streamlit.io
# 3. Connect repo → select streamlit_app/bitcoin_dashboard.py
# 4. Add secrets in the Streamlit Cloud UI (mirror your .env)
# 5. Deploy — live URL in ~2 minutes
Step 9 — Deploy this website (optional)

Host the platform on the web

GitHub Pages (free, automatic)
# In GitHub repo Settings → Pages
# Source: Deploy from branch → main → / (root)
# Your site: https://your-username.github.io/bitcoin-ds-platform
Netlify (drag & drop)
# Drag the project folder to netlify.com/drop
# Or connect GitHub repo for auto-deploy on every push
Vercel
npm i -g vercel
vercel deploy
# Follows vercel.json config if present — otherwise auto-detects static site
